# User Manual - ANR Dairy Management System (v1.0.0)

This guide provides instructions for daily operators and dairy collection agents using the ANR Dairy portal.

---

## 1. Authentication & Access

1. Open the ANR Dairy application in your browser or install the PWA shell on your home screen.
2. Enter your registered **Phone Number** and **Password** (e.g. Ramu Agent: `8888888888` / `Employee@123`).
3. Click **Sign In**. You will land on your designated dashboard.

---

## 2. Daily Milk Collection Entry

To log a milk collection entry (e.g. during a morning or evening shift):
1. Navigate to the **Daily Collection** menu in the sidebar.
2. Search for the farmer by code (e.g., `ANRF0001`) or select their name.
3. Choose the **Shift** (`Morning` / `Evening`) and verify the **Milk Type** (Cow/Buffalo).
4. Enter the physical metrics:
   - **Quantity (Liters)**: e.g. `10.5`
   - **FAT %**: e.g. `7.2`
   - **SNF %**: e.g. `9.0`
5. The system automatically queries active rate charts to display the calculated **Rate per Liter** and **Total Amount** in real-time.
6. Click **Save Collection**. A success toast will pop up, and an automated WhatsApp notification containing receipt details will be queued.

---

## 3. Reviewing Shift History

- Go to the **Shift History** page to view list entries recorded during the current shift.
- Toggle between Morning/Evening filters.
- If necessary, edit or remove entries before the shift lock is applied.

---

## 4. Farmer Directory & Passbook Lookups

- View the list of active members on the **Farmers Directory** page.
- Select any farmer to review their active collection histories.
- Click **Print Passbook** to launch a clean print layout formatted for standard A4 or Thermal receipt roll sizing.
- Toggle language modes in the settings menu to translate labels between English and Telugu instantly.
